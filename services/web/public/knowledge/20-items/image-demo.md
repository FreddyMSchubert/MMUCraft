## Image Demo Entry

Knowledge entries can include images. Locked entries will replace images with the default obscured image, while unlocked entries show the real image.

![A demonstration image for a custom server item](/assets/knowledge/demo/custom_item_demo.png)

Example image: a custom item note. Put the real file in the web public assets folder.

Suggested real file location: `services/web/public/assets/knowledge/demo/custom_item_demo.png`
