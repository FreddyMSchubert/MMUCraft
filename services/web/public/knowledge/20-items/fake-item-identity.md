## Fake Item Identity

Fake items reuse vanilla item IDs. The client sees a normal item, but custom model data and server-side components allow the server to treat that item as something special.

This is why two items with the same vanilla base can look or behave differently. The visible item type is only part of the story.

The server uses stable fake item IDs internally. These IDs are important because they let the mod recognise custom items even when the display name, lore, or resource pack art changes later.
