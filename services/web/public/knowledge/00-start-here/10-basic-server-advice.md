## Basic Server Advice

The server has several custom systems layered on top of vanilla Minecraft. Most of them are designed to feel like vanilla-adjacent discoveries rather than obvious plugin commands.

The most important habit is simple: read item names, hover over items, and test things carefully. Some items only work while held, some only work while equipped, and some only respond to specific interactions like right-clicking blocks or entities.
