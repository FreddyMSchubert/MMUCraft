## Server Resource Pack

The server resource pack controls how many custom items appear on your client. Without it, many fake items may look like ordinary vanilla items.

The behaviour is server-side, so the item can still work without the correct art, but the intended experience depends on the resource pack being enabled.

If custom items suddenly look wrong, check whether your client rejected or disabled the server resource pack.
