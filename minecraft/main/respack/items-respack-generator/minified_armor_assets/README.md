# Minified armor textures

Put your authored minified PNGs here. This folder mirrors `../vanilla_armor_assets/`: use `humanoid/` and `humanoid_leggings/`, with the same filenames as the base textures, including `enderite.png` and `leather_overlay.png`.

The 18 PNGs for the eight standard armor materials (including both leather overlays) are required for their minified models. Add `humanoid/turtle_scute.png` separately for the turtle helmet; it has no leggings texture. Until you add it, minified turtle helmets use the normal vanilla turtle texture. The generator copies your textures into the resource pack without generating or altering the art. The base Enderite PNGs live in `../vanilla_armor_assets/` and are copied into the pack as well.
