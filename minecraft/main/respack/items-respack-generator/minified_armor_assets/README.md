# Minified armor textures

Put your PNGs in both `humanoid/` and `humanoid_leggings/`. Each folder needs:

`chainmail.png`, `copper.png`, `diamond.png`, `enderite.png`, `gold.png`, `iron.png`, `leather.png`, `leather_overlay.png`, and `netherite.png`.

Use the same armor UV layout as the corresponding textures in `../vanilla_armor_assets/`. The resource pack builder copies these files unchanged. It leaves minified equipment variants out of the pack until all 18 PNGs are present.
