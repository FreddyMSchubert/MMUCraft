# Minified armor textures

Put your authored minified PNGs here. This folder mirrors `../vanilla_armor_assets/`: use `humanoid/` and `humanoid_leggings/`, with the same filenames as the base textures, including `enderite.png` and `leather_overlay.png`.

Add `humanoid/turtle_scute.png` for the turtle helmet, mirroring its base texture. It has no leggings texture. The generator copies these textures into the resource pack and creates minified equipment definitions when all 19 PNGs are present. It does not generate or alter the art. The base Enderite PNGs live in `../vanilla_armor_assets/` and are copied into the pack as well.
