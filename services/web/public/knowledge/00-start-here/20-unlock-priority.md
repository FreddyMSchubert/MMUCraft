## Knowledge Unlock Priority

Knowledge does not unlock in pure random order across the whole wiki. Each locked section has a priority number. Lower numbers unlock first.

For example, all priority `0` entries are unlocked before priority `1` entries. Within the same priority group, the next unlock is random.

This lets early discoveries teach basic mechanics before later discoveries reveal deeper, stranger, or more powerful interactions.
