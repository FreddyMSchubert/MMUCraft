## The Crafting Staff

The Crafting Staff is a convenience item for opening crafting functionality without needing to place a crafting table. This is especially useful while travelling, mining, or building in awkward spaces.

It is not meant to replace infrastructure entirely. Treat it as a portable tool rather than a full base management system.

> Tip: if an item opens a screen, avoid spam-clicking it. Wait for the server to respond before using it again.
