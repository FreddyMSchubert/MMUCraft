__Welcome to the MMU Minecraft Society!__ If you're reading this, your signup was successful. You can now join the server and start playing! *Please read this first though:*

If you want to have a Minecraft experience very close to Vanilla, you can do that, but the server also offers tons of fun stuff if you're into it. Some small teasers:

1. Powerful charms which grant strong abilites such as Veinminer, Walking on Walls and Ceilings, Increased Health, and over 20 more.
2. Many powerful new items, such as backpacks, an early-game alternative to Shulker Chests.
3. Tons of awesome cosmetics. Pirate Hat, Cat Ears, Sniffer Hood - Anyone?
4. Over 1000 new advancements which add many interesting challenges.
5. An economy with a centralized, stabilized currency you can use when trading with others.
6. Obamium Pyramid.

## Some tips before you get started

- **Use minecarts** - Their speed has been more than doubled, making it the fastest transportation method with the same speed as elytra. Powered rails can now be crafted with copper instead of gold.
- **Sunday Funday** - On sundays, all currency earned is increased via a multiplier and a bunch of shop items are discounted.
- **Build close to spawn** - There is no `/home` to avoid everyone living super far away from each other and never seeing each other. There is a way to teleport to the world spawn, but not your own respawn point.
